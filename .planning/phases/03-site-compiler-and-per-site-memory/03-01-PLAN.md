# Typed knowledge substrate and owned-site tracer

Add @juno/knowledge using existing Zod and filesystem primitives. Compile supplied safe page observations into strictly typed semantic page inventories, navigation relations and host-reviewed OperationSpec contracts. Store semantic role/name/scope only; no ephemeral refs, coordinates, field values, cookies, storage, query strings or credentials. Redact supplied known secrets and credential-shaped labels. Unknown affordances do not acquire executable behavior or benign risk from page text. Only host-reviewed, independently verifiable operations are included.

Persist per-owner/per-origin bounded version history atomically. Validate every reload, isolate owners, retain schema/structure/operation versions and region fingerprints, expose drift comparisons and deterministic semantic identities that survive reorder. Keep browser profiles and account credentials outside knowledge and exports. Integrate the existing fixture compiler/runner so new models contain a real typed contract, reload knowledge after process restart, and reject missing/corrupted/incompatible stored versions before execution.

Verify on real owned pages, with restarted stores, reordered/renamed controls, ambiguity, secret-shaped labels, malformed records, cross-owner isolation and export allowlists. This increment does not complete autonomous multi-page site exploration, generalized operation discovery, authenticated-site execution or semantic self-healing. Keep Phase 3 open until those compiler acceptance gates have broader site evidence; Phase 4 remains a separate dependency.

Threats: page-text injection, persisted executable instructions, secret/session leakage, path traversal, corrupted/tampered model, cross-workspace leakage and unbounded versions. No new third-party dependency.
