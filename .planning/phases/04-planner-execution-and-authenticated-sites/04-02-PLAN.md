User-authorized scope: bring the existing engine into the frontend and backend of hosted Juno. Execute inline through GSD's runtime compatibility fallback, on the existing PR #3 branch.

1. Promote the owned contact adapter into a reusable agent export. Add workspace-isolated backend services for saved plans, durable runs, cancellation, inspect-before-resume, independent results, screenshots and versioned site knowledge. Never accept user-selected origins, selectors, raw contracts or authority. Keep loopback applications private and bound server/browser concurrency and persisted data.
2. Make Agent the main application view. Provide an honest supported task composer, review-before-launch, live browser/progress, durable history, explicit safe resume, independent results, downloadable receipts and inspect/forget site memory. Preserve Research, personal Memory and the browser lab.
3. Connect the optional server-side language interpreter and existing reliability benchmark. Expose configuration/authentication errors without leaking credentials; deterministic task entry must work without a model key. Show actual benchmark outcomes with artifacts isolated by workspace.
4. Verify API ownership, schema/CSRF boundaries, persistence, task replay, stop/recovery, memory forgetting and failure handling with the existing test harness. Run repository regressions and Docker persistence checks; deploy to the existing Coolify application and verify hosted APIs. Update GSD evidence and PR #3. Offer recorded UI verification when implementation is complete.

This ships the existing bounded engine as a usable product. It does not claim arbitrary-site autonomy, authenticated real-account workflows, teach-by-showing, semantic self-repair or a working provider credential.
