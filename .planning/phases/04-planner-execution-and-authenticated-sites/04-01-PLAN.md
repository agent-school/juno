# Typed task runtime and interpretation foundation

This foundation is co-developed under the explicit Phase 4 scope in 03-02-PLAN.md. It does not bypass the remaining Phase 3 or authenticated-site gates.

1. Validate a complete typed task before browser actions. Bind task/request/model/contract identities and reject changed-input retries.
2. Ground trusted contracts against live accessibility observations and execute through the existing guard with separate host permissions.
3. Verify independent application state before and after each operation, journal expected/observed effects and recover after interruption without duplicate writes. Release cross-process exclusion after process death without expiring a live execution lease.
4. Accept intent interpretation through a provider-neutral interface. Reject unknown operations, raw actions, internal request keys and invalid parameters. Save accepted plans before execution; replay without more model calls.
5. Validate with a repeatable owned contact/follow-up workspace, a real process-kill boundary and adversarial provider fixtures. Attempt one live provider check, recording authentication failures honestly.

Completion means the bounded foundation is reproducible. It does not accept full EXEC-01, dynamic-field discovery, page extraction, interactive destructive confirmation, AUTH-01/02, semantic repair or arbitrary-site capability.
