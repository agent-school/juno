Design decision taken in this plan: an empty page or a page whose accessibility tree has no children parses to a valid PageTree with an empty children array; a null/undefined snapshot capture result raises SnapshotParseError. Reading never throws on empty content. Flagged for phase review.
- **[BRWS-02 / encoding]** Probe: "Whose definition of length/equality applies?" Design decision taken in this plan: accessible-name equality follows Playwright's own semantics — names are compared after Playwright's whitespace normalization, exact-match via getByRole exact:true is the durable-ref contract, and the parsed tree stores names verbatim as reported by the accessibility tree (no Juno-side normalization or truncation). Flagged for phase review.

Both decisions are implemented in Task 1/Task 2 and asserted by tests; changing them later touches only the parser/schema boundary.
