# Juno research desk redesign

## Intent

Jack requested a fundamental design rethink using Impeccable's anti-AI-slop references. The audience is Jack and early Juno evaluators performing a bounded research → remember → refresh loop. Design voice: observant, exact, composed. The interface should feel like a working research instrument, with results and durable context taking precedence over product claims.

## Changes

1. Replace the oversized headline and equal-weight setup cards with a compact research composer, persistent recent-task navigation, a readable results document and a working-memory rail.
2. Give memory its own searchable collection and type filters. Disclose note editing, defaults and workspace recovery when needed. Carry the same system through the Browser lab, receipts and roadmap.
3. Self-host Public Sans and Sora with licenses. Use semantic tokens, restrained blue actions, readable secondary text, explicit statuses, visible focus and responsive layouts. Preserve typed operations, server memory, source provenance and existing execution boundaries.
4. Add hash navigation and preserve expanded source/receipt disclosures during background polling. Avoid marketing heroes, repeated decorative badges, card grids, gradients and fake chat affordances.
5. Record the now-working custom hostname, validate build and existing tests, review the rendered design, deploy the verified revision with the existing volume, and update PR #2 without merging.

## References

- https://impeccable.style/slop/ — oversized italic serif headings, tiny interface text, redundant copy, card nesting, layout by content, contrast and reduced motion.
- https://github.com/pbakaus/impeccable/blob/28d0b7843080a7bf08fec3da473c05b897eabd6c/source/skills/impeccable/SKILL.md — intentional direction, product context, typography and functional UI.

## Acceptance

- Research, explicit memory saves, recipes, refresh, account recovery and browser execution retain their contracts.
- Navigation, field labels, source links, statuses, failure details and exports remain accessible.
- Main views fit narrow screens without horizontal page overflow; focused form editing is not erased by polling.
- `pnpm build`, unit tests and existing browser/API tests pass. UI-driven workflow testing requires Jack's approval; static visual review is separate evidence.
- `https://juno.agentschool.io/healthz` and deployed assets use valid HTTPS; the same persistent `/data` remains attached.
